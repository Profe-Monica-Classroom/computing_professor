# 🚀 CRUD Project: Registration of Persons (Computación 1. UNEXPO Guarenas Nucleus. Section 37)

This repository contains a complete academic resource designed for the **Computación 1 (Section 37)** course at the Guarenas Nucleus of **UNEXPO**. It is a practical example of how to build a modern web application following the **MVC (Model-View-Controller)** design pattern in both **Python (Flask)** and **PHP**. This was done using Google Antigravity AI, demonstrating what can be achieved with the collaboration between humans and AI.

---

## 📂 Estructura del Proyecto (Project Structure)

Este repositorio se divide en tres versiones especializadas. Haz clic en los enlaces para ver las instrucciones detalladas de cada una:

### 1. [Versión Python Local](ejemplo_python_crud/README.md)
Optimizado para ejecución en tu computador personal. Ideal para clases y estudio.

### 2. [Versión Python Cloud (Hugging Face)](ejemplo_python_crud_huggingface/README.md)
Listo para la nube con Docker y configuraciones de seguridad para producción.

### 3. [Versión PHP (MVC)](ejemplophp/README.md)
Ideal para servidores clásicos de Hosting. Incluye el script SQL para la base de datos.

---

## 🌟 Características Principales (Main Features)

- **Gestión de Datos (CRUD)**: Registro, consulta, edición y eliminación de datos personales básicos.
- **Registro de Usuarios**: Sistema de autoservicio para que los estudiantes aprendan a crear sus propias cuentas de acceso.
- **Seguridad Moderna (CAPTCHA)**: Verificación visual por imagen para proteger el acceso y registro.
- **Diseño Premium**: Interfaz profesional basada en el tema libre bootstrap llamado: "Clinic/Medicio", adaptada para un entorno académico de computación.
- **Multi-Plataforma**: Implementaciones listas para servidor local, Hosting PHP y despliegue en la nube con Docker.

## 🔧 Instalación Rápida (Quick Install - Python)

Si vas a ejecutar este proyecto en tu propia computadora:

1. **Instala las dependencias:**
   ```powershell
   python -m pip install flask gunicorn captcha
   ```
2. **Inicia el servidor:**
   ```powershell
   python app.py
   ```
3. **Accede:** `http://localhost:5000`
