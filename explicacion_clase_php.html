Estructura del Proyecto (MVC)

El patrón Modelo-Vista-Controlador separa la lógica en tres capas para mantener el código ordenado.

M: MODELO (Datos)

Archivos en /Model. Se encarga de hablar con la Base de Datos.

Ej: persona.php hace los SELECT, INSERT.
V: VISTA (Interfaz)

Archivos en /View. Es el HTML que ve el usuario.

Ej: Formularios, Tablas, Botones.
C: CONTROLADOR (Cerebro)

Archivos en /Controller. Recibe la petición y decide qué hacer.

Ej: "El usuario quiere guardar -> Llama al Modelo -> Muestra la Vista".

Conexión PDO (MySQL)

Usamos PDO (PHP Data Objects) para conectarnos de forma segura y orientada a objetos.

class Conexion {
    public static function StartUp() {
        // Conexión segura usando try-catch
        $pdo = new PDO('mysql:host=localhost;dbname=db', 'root', '1234');
        return $pdo;
    }
}

Autenticación y Sesiones

El manejo de usuarios se hace mediante $_SESSION.

Inicio (Login)

El usuario envía credenciales. Si son correctas, guardamos $_SESSION['user_id'] = 1;

Persistencia

Mientras navega, PHP recuerda quién es gracias a la cookie de sesión.

Protección

Antes de mostrar una página, verificamos: if(!isset($_SESSION['user_id'])) die('Acceso denegado');

Cierre (Logout)

Al salir, ejecutamos session_destroy(); para borrar los datos.
