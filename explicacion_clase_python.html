A diferencia de PHP donde mezclamos código lógica y HTML, en Flask separamos completamente. Jinja2 es el motor que "rellena" los huecos en el HTML.

Base de Datos (SQLite)

Usamos SQLite por simplicidad (un solo archivo), pero en Python nos conectamos mediante clases Modelo.

# Modelo en Python
class PersonaModel:
    def __init__(self):
        self.db_name = 'database.db'

    def listar(self):
        # Context Manager (with)
        with sqlite3.connect(self.db_name) as conn:
            cursor = conn.cursor()
            cursor.execute("SELECT * FROM persona")
            return cursor.fetchall()

* Nota: El uso de with asegura que la conexión se cierre sola, evitando errores.

Sesiones y Decoradores de Seguridad

El Decorador @login_required

En lugar de copiar y pegar el código de "verificar sesión" en cada función, creamos un decorador reutilizable.

@login_required 
def panel_privado():
    return "Solo admins"

Objeto Session

Flask maneja la sesión como un diccionario seguro (encriptado).

# Guardar
session['usuario'] = 'Juan'

# Leer
nombre = session.get('usuario')

# Borrar
session.clear()
